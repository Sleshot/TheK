# -------------------------------------------------------------------------------------
#  6. КАРТА: ТЕХНИЧЕСКОЕ ЗАДАНИЕ (критично, читать дважды)
# -------------------------------------------------------------------------------------
#
#  6.1 ОХВАТ
#    Весь городской округ Краснодара + ближайшая полоса пригорода:
#    bbox (lat S 44.90 … N 45.17) × (lon W 38.78 … E 39.24) — ~31 × 26 км (≈800 км²).
#    Внутри — весь Центральный, Карасунский, Прикубанский, Западный округа,
#    Прикубанское сельское поселение с Пашковским аэропортом и индустриальные зоны.
#
#  6.2 ИСТОЧНИК
#    Overpass API (OpenStreetMap). Запросы ТАЙЛАМИ (сетка 0.04–0.14°), с ретраями
#    и сменой зеркал; дедупликация по id; хранить сырой результат в engine/data_raw/.
#    ОБЯЗАТЕЛЬНЫЕ СЛОИ:
#      • ЗДАНИЯ: way["building"] — bbox здания (оцифрованный контур упрощаем до
#        ориентированного прямоугольника) + building:levels (этажность → высота h = levels*3.05 м;
#        если этажности нет — оценочная по типу и площади: apartments 6–15 этажей в центре,
#        частный сектор 1–2, commercial 2–8 и т.д., плюс детерминированный джиттер).
#        Ожидаемый объём: 150–200 тыс. зданий — НЕ ПРИДУМАННЫЕ, реальные из OSM.
#      • ДОРОГИ: way["highway"] всех классов (кроме footway/path/cycleway/steps),
#        с именами и классом. Полигоны площадей (area:highway) — при наличии.
#      • ВОДА: natural=water + waterway (riverbank/river/canal/stream), В ТОМ ЧИСЛЕ
#        мультиполигоны-relations (Кубань — главная река, обязана быть!).
#      • ЗЕЛЁНЫЕ ЗОНЫ: leisure=park/garden/..., landuse=forest/meadow/grass,
#        natural=wood/scrub/grassland. Внутри парков/лесов — рассеянные деревья
#        (детерминированный генератор, плотность: лес ~1/30 м², парк ~1/60 м²).
#      • LANDUSE подложки: residential/industrial/commercial/garages/farmland —
#        для разноцветной «текстуры города» под ногами.
#      • ЖД: railway=rail/tram с геометрией.
#      • POI: именованные стадионы/театры/музеи/вокзалы/ТРЦ/больницы/вузы/парки/
#        аэродром — для подписей на полной карте и в мире (иконки на миникарте).
#
#  6.3 ПРОЕКЦИЯ И ТОЧНОСТЬ
#    Локальная метрическая система ENU: начало в центре bbox (45.035, 39.01);
#    x = (lon−lon0)·111320·cos(lat0), z = (lat−lat0)·111139  (ошибка < 0.3% на диагонали — допустимо).
#    Все игровые координаты в МЕТРАХ, высота земли 0 (равнина; Краснодар плоский).
#    Формат city.krd — little-endian, заголовок с магией 'THEK', версией,
#    счётчиками и bbox; секции выровнены по 4 байта; строки названий — UTF-8.
#
#  6.4 ПРАВИЛА ОТРИСОВКИ ГОРОДА (визуальная правдоподобность)
#    - Здания: 5 граней (без дна), верхняя грань — «кровля» темнее; фасады —
#      процедурные окна в шейдере (сетка 3.0×2.9 м, подсвеченная доля окон ночью),
#      цвет из палитры по хэшу id здания (жилые — тёплые, промка — холодные).
#    - Дороги: ленты по полилиниям; ширина по классу (motorway 22 м … service 4 м);
#      осевые разметки у primary+; трамвайные/ЖД пути — тёмные полосы 3 м.
#    - Земля: базовый градиент газона + цветные районы по landuse + лёгкий шум.
#    - Вода: полупрозрачные полигоны y=0.3 с анимированной рябью и отражением неба.
#    - Деревья: 2 скрещённые текстурированные плоскости (альфа-выборка в шейдере),
#      только на ближних чанках (fade к 700 м), без них дальний план не выглядит пустым —
#      зелёные полигоны дают массу.
#    - Небо: градиентный купол + солнце + дрейфующие облака (value-noise в шейдере);
#      туман exp2 tied к дальности прорисовки; режимы день/«золотой час»/ночь [T].
#
#  6.5 ПРИЗНАКОВЫЕ МЕСТА (обязаны угадываться без подписи)
#    Проспект/ул. Красная (главная ось), река Кубань вдоль юга центра, Парк Галицкого,
#    стадион «Краснодар», Краснодар-1 (вокзал), ТЦ «Галерея», Екатерининский сквер,
#    Чистяковская роща, Ботанический сад, аэропорт Пашковский на северо-востоке.
#    Реальные POI-подписи из OSM выводим на полной карте и в мире по близости.
#
# -------------------------------------------------------------------------------------
#  7. ГЕЙМПЛЕЙ: СУПЕРСИЛА A-TRAIN (детальная спецификация)
# -------------------------------------------------------------------------------------
#
#  Управление (настраиваемо через файл конфига, значения ниже — дефолт):
#    WASD — движение | мышь — обзор | SPACE — прыжок | SHIFT (удерживать) — «газ» сверхскорость
#    Q / E — ступени скорости вниз/вверх | X — «ФАЗА» (проход сквозь здания) вкл/выкл
#    T — время суток | TAB или M — полная карта | F1 — помощь | ESC — пауза
#
#  Скоростные модели:
#    - Шаг 2.2 м/с, бег трусцой 7 м/с (стамина бесконечна — мы супер).
#    - Режимы сверхскорости (ступени целевой скорости): 30 / 75 / 160 / 340 м/с.
#      Ускорение 45 м/с², торможение 60 м/с²; раскачка камеры и крик ветра
#      растут нелинейно (gain ~ v^1.4).
#    - При скорости > 25 м/с нормальные столкновения со зданиями ОПАСНЫ:
#      без «фазы» — жёсткий удар (отскок, тряска, красная вспышка, −15 Compound V),
#      с «фазой» — проходим сквозь, шлейф частиц «стекла», звук шелеста пакли.
#    - Компаунд V (энергия): 100 ед. Расход: 0.5·(v/10)^1.3 ед/с при v>10 м/с;
#      восстановление 4 ед/с при v<=10. При нуле — «отходняк»: принудительный
#      сброс до трусцы, затемнение по краям, сердцебиение 5 секунд.
#    - Счёт фана: счётчик «разогнался до звука» (достижение 340 м/с) + метры,
#      пройденные сквозь зданий («фазометр»), выводятся в HUD-панель статистики [F3].
#
#  Эффекты скорости (все связаны с текущей скоростью плавными параметрами):
#    FOV 75° → 105°, радиальные speed-lines (аддитив, 48 линий, интенсивность по v),
#    виньетка, тонкое хроматическое смещение по краям, motion blur через
#    аккумиляцию предыдущего кадра (FBO, плавный коэффициент по v; без FBO — пропуск),
#    микро-тряска камеры s(v), пыльный след за спиной (point-sprites),
#    аудио: шум ветра (LP/HP-фильтр по v), низкий рёв при v>150.
#
#  Мир живой и честный: коллизии со зданиями (AABB, разрешение по осям и слайд,
#  swept-тест при сверхскорости туннелирования не допускает: рейкаст по вектору
#  хода через spatial hash), нельзя покинуть bbox (мягкий возврат с туманом),
#  вода не убивает, но «гасит» скорость до 5 м/с и брызгает камерой.
#
#  HUD (русские подписи, шрифт-атлас, левая=компактная верстка):
#    • Большой спидометр км/ч + режим (ШАГ/БЕГ/СВЕРХ-1..4 + «ФАЗА》)。
#    • Полоса Compound V (красная, мерцает при <20%).
#    • Текущая улица под перекрестием (ближайший именованный way в 40 м).
#    • Миникарта справа внизу (радиус 1.5 км; дороги tertiary+, игрок-стрелка, север, POI-подписи).
#    • Полная карта [TAB]: весь город, здания точками не рисуем — дороги/вода/парки/POI + метка игрока.
#    • Подсказки управления первые 20 секунд и по F1.
#    • FPS, координаты, статистика (F3).
#
#  Экраны: титульник (логотип «THE K: A-TRAIN», пульс «НАЖМИТЕ ENTER», строка атрибуции
#  OSM и дисклеймер фанатского проекта), пауза (продолжить/сенса/FOV/громкость/
#  дальность прорисовки/выйти), экран помощи F1.
#

#  9. КОНВЕЙЕР ДАННЫХ (engine/tools/)

#  fetch_overpass.py — тайловая выгрузка (см. 6.2) с ретраями; идемпотентен

# -------------------------------------------------------------------------------------
#  10. АРХИТЕКТУРА И КОД (стандарты)
# -------------------------------------------------------------------------------------
#
#  engine/src/thek.h     — типы, конфиг, API-макросы, математика (vec/mat) инлайн.
#  engine/src/platform.h — изоляция ОС: окно/ввод/таймер/звук (win) и заглушки (selftest).
#  engine/src/glload.c/h — загрузчик OpenGL-функций + утилиты шейдеров/VBO/FBO.
#  engine/src/city.c/h   — city.krd: загрузка, чанки, меш-генерация, spatial hash,
#                          запросы (ближайшая улица, пересечение луча, коллизии).
#  engine/src/render.c/h — пайплайн: небо/земля/вода/здания/дороги/деревья/частицы/
#                          оверлеи/HUD, speed-FX, day/night, миникарта/полная карта.
#  engine/src/game.c/h   — состояние игрока, способности A-Train, логика Compound V,
#                          камера/тряска, статистика, экраны (title/pause/help), конфиг-файл.
#  engine/src/audio.c/h  — процедурные источники звука + миксер + waveOut цикл.
#  engine/src/font.c/h   — атлас, UTF-8 разбор, текстовый рендер.
#  engine/src/main_win.c — WinMain: окно, WGL-контекст, ввод (raw mouse), цикл,
#                          vsync (wglSwapIntervalEXT если есть 60/30), graceful shutdown.
#  engine/src/selftest.c — linux-сборка: грузит city.krd, прогоняет 5000 кадров физики
#                          (в т.ч. сверхскоростной проезд через центр), проверяет инварианты
#                          (нет NaN, коллизии разрешены, bbox-инварианты, чтение всех секций).
#
#  Правила кода:
#   • C99, компилируется без варнингов при -Wall -Wextra (кроме заведомо безобидных).
#   • Никаких глобальных malloc/free в кадре; пулы фиксированного размера, статические буферы.
#   • Все константы геймплея — в одном блоке THEK_TUNING (быстрая балансировка).
#   • Комментарии по-русски, по делу; сложные места — с пояснением «почему так».
#   • Абсолютные пути запрещены; data ищется рядом с exe (data/<file>).
#
# -------------------------------------------------------------------------------------
#  11. СБОРКА И УСТАНОВЩИК
# -------------------------------------------------------------------------------------
#
#  engine/build.sh — единая точка входа:
#    1) bake данных (если отсутствуют артефакты);
#    2) zig cc -target x86_64-windows-gnu -O2 → dist/TheK-A-Train.exe (+ copied data);
#    3) linux selftest-сборка и прогон (обязателен зелёный статус);
#    4) NSIS: installer.nsi → ins/TheK-A-Train-Setup.exe
#       (русский+английский, Modern UI 2, выбор папки, лицензия, ярлыки
#       в меню «Пуск» и на рабочем столе (опционально), деинсталлятор,
#       корректная запись в реестр, иконка; сжатие LZMA solid).
#
#  Результат: двойной клик по ins/TheK-A-Train-Setup.exe → игра за 1 минуту.
#
